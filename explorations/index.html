Four portfolio directions

Parked explorations from 18 Sep 2026. Each card opens a complete single-page draft built from the resume. Same facts, four different visual theses. Option D (Surfaces) was chosen and lives at the project root; the other three are kept here for future reference.

A · typesafe.ai homagelight

Five Years, Two Engineers, One Whole Platform.

Near-white canvas, giant tight grotesk headline, mono labels, hard color-block sections (pink, sage, black), corner crop marks, and retro system windows showing a live agent trace, a LiveKit room, and an IST clock.

Inter Tight · Inter · JetBrains Mono. Closest to your stated taste.
B · Tracedark

Your career as a span waterfall.

The page is a tracing tool: roles are root spans, shipped features are child spans on a 2021→2026 axis, color-coded by AI / real-time / platform / search. Hover a span for details, stack rendered as span attributes.

Geist · Geist Mono. Speaks directly to Langfuse / LLM-ops hiring managers.
C · Changeloglight

Release notes for one full-stack engineer.

Sticky bio column plus a versioned changelog, newest first, with migrations rendered as diffs (twilio-video → livekit, algolia → typesense). Calm, editorial, developer-native. Ages well.

IBM Plex Sans · Plex Serif · Plex Mono. Best if you plan to write.
D · Surfacesdark

Every card is a thing you shipped.

A bento grid where each card is a miniature working replica of a product surface: the voice interview call, the tool-call DAG, the −16% spend sparkline, the API request, the billing seats, the search filters.

Instrument Sans · DM Mono. Most "product" feel; strongest at showing UI craft.

Fonts load from Google Fonts, so the pages need internet the first time. Dates for individual features inside a role (option B spans, option C versions) are approximate and should be corrected. Your phone number is deliberately left off every page. See DESIGN-RESEARCH.md for the research behind these.
